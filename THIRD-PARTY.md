# Included UE4SS runtime

The installation ZIP includes the official [RE-UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) experimental build `v3.0.1-1136-g35d1795d` (downloaded from its [release page](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest)). The upstream ZIP's SHA-256 is `050948bdf6b4aae2ff8d834aaebadbf7535d4cb8478fbb579966a5ca3142f86a`.

The package adds the BodycamHostTest mod, enables it in UE4SS's mod list, and sets UE4SS's debug GUI to DX11 for the tested Bodycam installation. UE4SS's original MIT license is retained at `ue4ss/LICENSE` inside the ZIP. The Lua mod is licensed separately under this repository's [MIT license](LICENSE).
